# 집회·시위 주민안내 QR 1차 버전

QR 코드를 촬영한 주민에게 집회 장소·시간, 보행자 통행, 교통·우회, 소음, 경찰 현장조치 등을 모바일 화면으로 안내하는 **정적 웹앱 프로토타입**입니다.

## 파일 구조

```text
assembly-qr-v1/
├─ index.html      # 주민용 화면
├─ admin.html      # 관리자 입력 화면
├─ style.css       # 디자인
├─ app.js          # 주민 화면 로직/저장 데이터
├─ admin.js        # 관리자 입력 로직
└─ README.md
```

## GitHub Pages에 올리는 방법

1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더의 파일 5개 + README.md를 업로드합니다.
3. Repository의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, Folder는 `/ (root)`로 선택합니다.
6. 저장하면 GitHub Pages 주소가 생성됩니다.
7. 생성된 주소의 `index.html`이 주민용 페이지입니다.
8. `admin.html`은 관리자 입력 화면입니다.

## QR 만들기

GitHub Pages 주소가 예를 들어:

`https://계정명.github.io/assembly-qr-v1/`

라면 이 주소를 QR 생성기에 넣어 QR을 제작합니다.

QR은 집회별로 새로 만들 필요 없이 **주민용 페이지 주소 하나를 고정**하는 것을 권장합니다.

## 중요: 현재 버전의 한계

이 버전은 서버/API 없이 동작하도록 만들었기 때문에 관리자 입력값이 **관리자 기기의 브라우저 localStorage에만 저장**됩니다.

따라서:

- 관리자 휴대폰에서 입력한 내용이 다른 사람의 휴대폰에 자동으로 전달되지 않습니다.
- 브라우저 데이터를 삭제하면 입력내용도 삭제됩니다.
- `admin.html`에는 실제 인증 기능이 없습니다.
- 실제 경찰 업무에 공개 운영하기 전에는 서버 데이터베이스와 관리자 인증이 필요합니다.
- 개인정보, 집회 신고서 원문, 대표자 개인정보 등 공개가 적절하지 않은 정보는 입력하지 마십시오.

## 2차 버전 권장 구조

실제 운영을 목표로 한다면 다음 구조로 전환합니다.

```text
경찰관 휴대폰
   ↓
관리자 로그인
   ↓
집회정보 DB
   ↓
주민용 모바일 페이지
   ↓
고정 QR
```

권장 추가 기능:

- 관리자 로그인/권한관리
- 집회 등록·수정·종료
- 여러 집회 동시 관리
- 집회 위치 지도
- 보행로/우회로 이미지
- 현재 위치 기반 주변 집회 검색
- QR 접속 통계
- 집회 종료 자동 처리
- 게시정보 변경 이력
- 공용 서버 DB
